# To-Doom-
# プロジェクト名
To-Doom!

## 概要
授業課題で一夜漬けで作ったゲーム。タスクを抱える人がひたすらはタスクを物理的に破壊する。

## 使い方
リポジトリをクローンし、unityにインポートする。
操作にはNovation Launchpadが必要である。

## ゲームルール
Launchpadをcustomモードに切り替え、エリアごとの発光を四色に分ける。
ボタンを押すこと物体が射出され、押すボタンの色で射出物の種類(投射y成分が違う)を選択。(4種類)
押す強さ(ベロシティ)で射出威力(投射x成分)を選択。(127段階)
ステージ上にある障害物(タスク)に投射した物体を当てることで消滅させることができ、永遠に続く。
開始8秒後からタスクが急激に連続的に増加する。
プレーヤーがタスクによって画面外に押し出され行動不能になったらゲーム終了(死亡)であるが、その後もタスクが増えていく。
処理落ちするまでゲームは終わらない。(授業課題という性質上、終了イベントを設定する時間がなかった。)
